LECTURA DE ARRIBA ABAJO

Tipos: US02Y → US10Y → 10Y-2Y → breakeven → DE02Y. Primero mira qué descuenta la política monetaria; después el largo plazo y la inflación esperada.

Divisas: DXY + EUR/USD. Te dicen hacia dónde se mueve el dólar y si existe divergencia Fed/BCE.

Economía real: Brent + TTF + cobre. Úsalos para separar energía, shock europeo y pulso industrial.

Refugio: oro + plata. Contrástalos siempre con DXY y tipos.

Riesgo: VIX + BTC + bolsas. No significan lo mismo: VIX mide demanda de protección; BTC es un termómetro más imperfecto de apetito especulativo.

COMPARAR SERIES

En los gráficos TradingView usa el botón + / “Compare or Add Symbol” para superponer variables y cambia la escala a Percentage cuando mezcles unidades distintas. Las dos series FRED se muestran aparte porque TradingView no autoriza su embed.

FRECUENCIA DEL DATO

La app prioriza que todos los gráficos sean visibles gratis. FRED se muestra como gráfico oficial diario. Cuando un futuro de una bolsa no puede incrustarse legalmente en un widget, se usa un proxy TVC/CFD muy correlacionado y se indica en el nombre del gráfico. No interpretes un proxy como si fuera exactamente el mismo contrato.

INSTALAR EN ANDROID

Una vez publicada por HTTPS, abre la web en Chrome → menú ⋮ → Añadir a pantalla de inicio / Instalar aplicación. Se abrirá como una app independiente.
